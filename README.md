## Featured Projects

### [SisGeS — Military Secretariat Backend](https://github.com/alexandreohiro/sisges-showcase)
`Python` · `FastAPI` · `SQLAlchemy` · `Alembic` · `pytest` · `JWT` · `ODT/PDF`

Production backend for Brazilian Army's administrative secretariat. Handles personnel records, document compilation, LGPD-compliant data processing, and role-based access control.

- Full REST API with JWT auth, CSRF protection, and layered permission system
- Compiler pipeline: military records → legally-formatted ODT/PDF documents
- 100+ integration tests · MySQL + SQLite · zero-downtime Alembic migrations
